# Trạng thái repo CIRNET CLI

[English](../en/index.md) · [Repo](../../README.md)

Repo hiện chứa giới thiệu dự án và [giấy phép](../../LICENSE). Git chưa theo
dõi tệp thực thi CLI, manifest gói, script build hay workflow CI. Hướng dẫn
cài đặt và lệnh sẽ thuộc repo này khi có implementation. Trình khởi chạy
Windows hiện hành thuộc [CIRNET Remote](https://github.com/cirnetlab/cirnet-remote).
